# torudake-app — 撮って送るだけ帳簿

> レシートは、撮って送るだけ。

家族で経営する小さな会社のための経理アプリです。現場の人はレシートを撮って送るだけ、経理担当は仕訳候補を直して承認するだけ、月末は締めまでの残りが「あと何件」で見える、という分担を目指します。

最初の利用者は有限会社 丹内建機サービス（産業用機械の修理・溶接・加工）です。会社名・決算月・分類・口座などの会社ごとの値はコードに書かず、会社設定として持ちます。

## 状態

設計と発表準備の段階です。アプリ本体はまだありません。

## 主な機能（予定）

1. **撮って送る**：スマホで撮影して送信。同じ写真の二重送信は止める
2. **仕訳候補を直して承認**：写真を見ながら日付・金額・分類を入れる。承認するまで帳簿に入らない
3. **締めナビ**：未処理・下書き・通帳との差を「あと何件」で表示し、0件で月を締める

## 技術構成（予定）

| 役割 | 採用 |
|---|---|
| API・業務ロジック | PHP 8.3 + Laravel 12 |
| 画面 | Next.js（スマホのブラウザで使う） |
| DB | MySQL 8.0（金額は整数円） |
| 認証 | Laravel Fortify + Sanctum（メール確認・2段階認証） |
| 権限 | Policy / Gate（会社所属とロールを先に検証） |
| 証憑 | S3互換ストレージ（暗号化・SHA-256・短寿命の署名付きURL） |
| ジョブ | Laravel Queue（Redis） |
| テスト | Pest / Vitest / Playwright |

Laravel は「間違った数字を確定させない」ために使います。権限は Policy でサーバー側に判定し、承認・取消・締めは `DB::transaction` と行ロックで1回だけ確定させます。
