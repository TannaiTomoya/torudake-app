## 1. 目的

> **家族経営の経理担当が、月末にレシートを書き写す夜を、撮って送るだけでなくす**

あわせて、**社長が承認に時間を取られず、月末を待たずに会社の数字を見て決められる**ようにする。社長の時間を、売上を立てる仕事に戻す。

決算書・申告は税理士と財務王に任せる。このアプリは、その手前の**経費の入口**と、**社長が決めるための数字の窓**を担う。

## 3. 利用者と役割（版3.0 で変更）

最初の利用者は**有限会社 丹内建機サービス**（産業用機械の修理・溶接・加工。7月決算）。売上の大半は、**紹介でつながった固定の取引先2社**。個人のお客さんは少ない。

| 人 | ロール | やること | やらないこと |
|---|---|---|---|
| 現場（社長・従業員・経理） | 送る人 | レシートを撮って、**まとめて送る** | — |
| 母（経理担当） | editor | AIの下書きを直して**保存＝確定**（Excel にも入る）。月に1回、財務王・販売王の帳票を撮って取り込む | — |
| 父（社長） | owner | **通知を見る。社長の画面で数字を見て決める。気になる仕訳だけ見て、違えば経理に戻す。** Excel をいつでも見る | **承認しない。締めない。**（仕事の流れを止めない） |
| 作者 | 所属なし | 開発・保守 | 日々の入力、本番データを見る |

- ロールは5つ（owner / admin / approver / editor / viewer）のまま。丹内建機で使うのは owner と editor と「送るだけ」。
- **確定は経理の保存で行う**（作る人と確定する人が同じになる。守りは §6.2 で補う）。
- 将来、経理を他人に任せるときに備え、会社設定に「**社長の承認が必要な金額**」を残す（既定は「なし」）。

## 4. 業務の流れ（版3.0）

```
[現場] 撮る → ためる → もう1枚 → まとめて送る →「送れました（n枚）」
   ↓ AI：読み取り・分類・仕訳の下書き・検算
[経理] 下書きを直す（理由を選ぶ）→ 保存＝確定 → 帳簿と Excel に1行入る
   ↓                         └→「あと n 件」が減る → 0件で「今月の帳簿ができました」
[社長] 週1回の通知 → 社長の画面：ひとこと・三期比較・気になる仕訳・来月の見込み
                       └ 違えば理由を付けて「経理に戻す」（止めない。経理が直して再保存）
[経理] 月1回：財務王・販売王の帳票（三期比較・顧客別）を撮って取り込む
```

| いつ | 誰 | やること | かかる時間（目安） |
|---|---|---|---|
| レシートをもらったその場 | 現場 | 撮って、まとめて送る | 1枚10秒 |
| 週1回 | 経理 | AIの下書きを直して保存 | 1枚30秒 |
| 週1回（月曜の朝） | 社長 | 通知 → 社長の画面を見る | **1〜3分** |
| 月1回 | 経理 | 財務王・販売王の帳票を撮って取り込む | 5分 |

## 6. データの扱い

### 6.1 決まり
| 項目 | 決まり |
|---|---|
| 写真 | 入力のための一時データ。**30日で自動削除** |
| 正本 | レシートは紙。売上・決算は財務王・販売王 |
| アプリに残るもの | 読み取った全文、写真の SHA-256、仕訳、直した前後・理由・間違いの型、取り込んだ月ごとの数字、AIの記録、監査記録 |
| AIへの送信 | Claude（Anthropic API）。学習には使われない（商用規約） |
| 会社の分離 | すべて会社に属し、他社からは見えない |
| 金額 | 円の整数（税込） |
| 費用の上限 | 月 $20（$10 で通知）、1社1日100回 |

### 6.2 経理の保存＝確定にしたことの守り（作る人と確定する人が同じ）
1. **AIがもう一人の目**：保存の前に、AIの検算（重複・私的支出・貸借）を必ず表示
2. **社長は事後に、気になるものだけ見る**：条件に合う仕訳を週1回まとめて通知。違えば戻す
3. **記録が残る**：誰が・いつ・何を直したかがすべて残る
4. **税理士が年1回見る**

### 6.3 実在のデータ（社長から受け取った帳票）
- 受け取ったもの（2026-10-24）：顧客別売上集計表（前期・今期8〜9月、**取引先名は写さずに撮影**）、売上高三期比較グラフ（3期分の月ごとの売上）
- **デモには使わない。** デモは同じ形の架空の数字
- **リポジトリ（公開）に入れない。** 本番に社長だけが見られる形で入れる
- 使うのは月ごと・取引先ごとの**合計だけ**。取引先の名前・伝票・個人名・口座番号は扱わない
- バックアップファイル（`ZAIBKUP.ZAI`）は読み込まない：独自の形式で仕様が公開されていない・版が変わると読めなくなる・会社のすべてが入っている・サポートを受けられない。使い終わったら共有を外す

## 7. 社長の画面の考え方（dlab の知見）

| 知見 | 設計への当て方 |
|---|---|
| 脳は一度に1つ（[シングルタスク](https://daigovideolab.jp/play/Pe2dDQ54jeTMLKWxokfc)） | 1画面。ひとことは、一番大きな変化を1つだけ |
| 比べ方で判断を誤る（[お金で損する人、得する人の心理学](https://daigovideolab.jp/play/1532624105)） | 金額の差を主に、%は添えるだけ。**前年の同じ月**と並べ、季節の波に惑わされない |
| 思い込みをデータで確かめる（[12のデバイアスガイド](https://daigovideolab.jp/play/1552229589)） | 原因を外（景気など）に置く前に、数字で確かめる材料を出す（例：売上の柱＝上位2社の割合） |
| 見積もりは幅で（[戦略的悲観術](https://daigovideolab.jp/play/D2SQ2WUQq4MZCYBFlMeo?t=3334)） | 来月の見込みは、中央値と8割の範囲 |
| 変化を恐れる相手には変える量を小さく（[変化を恐れる相手を説得する12の方法](https://daigovideolab.jp/play/l6Sda33p0unGwC1q4cjp)） | 社長が見慣れた**三期比較グラフと同じ形**にする。販売王・財務王はそのまま |
| 習慣はシンプルなほど続く（[習慣化の科学](https://daigovideolab.jp/play/1456669190)） | 週1回・同じ曜日・1行の通知。社長は承認も締めもしない |
| 確認は決めた最小限（[決断ミスをなくす7つのアプローチ](https://daigovideolab.jp/play/CmgrIOcXQG5QlImo28aU)） | 社長が見る仕訳は、決めた条件に合うものだけ |

AIは「何が起きたか」と「理由の見立て」と「確かめるとよい点」まで。**決めるのは社長**。

## 8. デモ（副市長、3分）の流れ（版3.0）

| 時間 | 場面 | 画面 |
|---|---|---|
| 0:00 | 「母は月末の夜にレシートを書き写しています。社長の父は、月末まで数字が見えません」 | ライブ画面「あと1件」 |

| 1:00 | 経理が直して理由を選び**保存＝確定** → **Excel に1行入る** | ライブ画面＋Excel |

| 2:40 | 「**社長は承認しなくていい。週に1回、この1画面を見て決めるだけです**」→ 最後のお願い | 社長の画面 |

数字はすべて架空。「あと n 件」は 1 → 3 → 0。
