# 画面遷移の整理（2026-10-24）

## 現状

経理の送信→AI下書き→手直し→保存→仕訳帳・Excel、従業員のまとめて送信、社長の三期比較・ひとこと・見込み・仕訳の戻し、AI記録と学習データ出力、月別売上帳票の取り込みは実装済み。

通知、顧客別帳票の取り込み、既存Excelの列対応などは未実装。未実装画面へのリンクを追加することで埋め合わせない。帳票取り込みの権限は [認可ルール](authorization.md) の未確定事項を参照。

## 経理がホームへ進めない条件

通常の新規ログインはホームに着く。しかし、未ログインで社長の画面・ライブ・他社URLなどを開くと、Laravel が `url.intended` にそのURLを保存する。Fortify の通常ログイン・2段階認証ログインの応答はこのURLを `/dashboard` より優先するため、経理のログイン後に403または404となり、会社ホームへ振り分けられない。

両方のログイン応答で古い遷移先を消す。`/dashboard` → `User::homeUrl()` の既存経路を必ず通す。JSONログインの応答形式は Fortify のまま。

## 修正した不整合

| 箇所 | 修正前 | 修正後 |
|---|---|---|
| 通常ログイン・2段階認証ログイン | 古いURLが役割別ホームより優先 | 古いURLを消し、役割別の入口へ |
| 会社のミドルウェア順序 | 2段階認証の判定が先で、対象会社を記憶する前に以前の会社へ転送。他社・無効な所属でも一部URLはホームへ転送 | 会社の所属判定・記憶を先に行い、対象会社の初期設定画面へ。他社・無効な所属は404 |
| 2段階認証前のサイドバー | 開けない業務画面へのリンク、会社の件数を表示 | ホームと個人設定への入口を表示。業務リンク・件数は認証設定後に表示 |
| 社長・管理者のホーム | 送信・手直し・AI記録への入口がなく、URLの直打ち等が必要 | 主な社長画面の下に、許可された3つの作業へのリンク |

## 遷移

| 利用者 | ログイン後 | 主な経路 | 設定から戻る |
|---|---|---|---|
| 経理（editor） | 会社ホーム | 直して保存→原資料→次の原資料／一覧、送信、仕訳一覧→詳細、Excel | 会社ホーム |
| 従業員（送るだけ） | 送信画面 | 写真をためる→まとめて送信→続けて撮る、個人設定・ログアウト | 送信画面 |
| 社長（owner） | 会社ホーム | 社長の画面→気になる仕訳→詳細→経理に戻す、帳票取り込み、Excel。ホームから送信・手直し・AI記録。ライブの Esc はホーム | 会社ホーム |

2段階認証がまだなら入口に初期設定カードを表示し、確認・復旧コードの保管後に同じ会社の入口へ戻る。複数会社に所属する場合は最後に開いた有効な所属会社へ戻る。

## 全会社ルートの監査

全14種類を `tests/Feature/RoutingTest.php` で検証。6種類の役割の許可／403、画面内の会社リンクの到達性、未ログインのログイン誘導、他社・無効な所属の404を確認する。子の実在IDを使い、原資料・仕訳・写真・ダウンロードも含める。
